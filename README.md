# Reports in an Hour

Пакет подготовки запуска практикума «Отчёты за час: AI для руководителя»: правила работы агента (AGENTS.md), журнал решений (PROJECT_MEMORY.md) и бриф запуска — собраны с помощью ИИ-агента.

## Структура

- `source/` — исходные материалы (продукт, аудитория, статус, тон)
- `templates/` — шаблоны AGENTS.md, PROJECT_MEMORY.md, брифа запуска
- `tasks/` — задания практики (аудит → правила → память → бриф → проверка)
- `CHECKLIST.md` — чек-лист готовности
